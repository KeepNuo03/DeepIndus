# DEEPINDUS 工业缺陷检测系统 - 前端项目说明

## 📋 项目概述

**项目名称：** DEEPINDUS 数字化工业核心管理引擎  
**技术栈：** Vue 3 + Vite + Tailwind CSS + ECharts + Iconify  
**开发日期：** 2026-02-03  
**项目状态：** MVP 已完成

---

## 🎯 系统功能模块

### 已完成模块（9个）

| 序号 | 模块名称 | 路由路径 | 功能说明 | 优先级 |
|-----|---------|---------|---------|--------|
| 1 | 用户认证 | `/`, `/login` | 用户登录、注册 | P0 |
| 2 | 实时检测 | `/detect` | 视频流监控、AI实时检测、多摄像头管理 | P0 |
| 3 | 数据大屏 | `/dashboard` | KPI指标、趋势图表、报警列表 | P0 |
| 4 | 历史查询 | `/query` | 检测记录查询、筛选、分页 | P0 |
| 5 | 缺陷详情 | `/defect/:id` | 缺陷图片、检测分析、处理跟踪 | P0 |
| 6 | 生产线管理 | `/production` | 生产线监控、摄像头配置、班次管理 | P0 |
| 7 | 产品管理 | `/product` | 产品库、质量标准、检测配置 | P0 |
| 8 | AI模型管理 | `/model` | 模型版本、性能对比、部署管理 | P1 |
| 9 | 用户权限管理 | `/users` | 用户管理、角色权限、操作日志 | P2 |

## 🔐 认证流程

1. 用户访问 `/` 默认跳转到登录页面
2. 登录成功后跳转到 `/detect` 实时检测页面
3. 后续页面需要验证用户身份（待后端实现 token 验证）

---

## 📊 数据流转

```
用户登录 → 获取 Token → 实时检测 → 
生成检测记录 → 查询历史记录 → 
查看缺陷详情 → 人工复核 → 生成报告
```

## 🛠️ 技术要点

### 前端状态管理
- 目前使用组件内部 `data()` 管理状态
- 建议后续引入 Pinia 进行全局状态管理

### 路由守卫
- 需要在 `router/index.js` 添加路由守卫
- 验证用户 token 是否有效
- 未登录重定向到登录页

### HTTP 请求
- 建议使用 Axios
- 需要封装统一的请求拦截器
- 统一处理错误和 Token
