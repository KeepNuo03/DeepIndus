# 安卓端试点方案（A-01 产线）

## 试点目标
- 验证“PC全量检测 + 安卓现场复核/抽检”的双端协同闭环。
- 在不迁移 PC 全功能的前提下，提升现场处理效率与数据回传稳定性。

## 试点范围
- 线体：`A-01`
- 角色：质检员、生产主管（安卓端）
- 周期：2 周

## 成功指标
- 任务闭环率 >= 95%
  - 口径：当日 fail 记录中，`processStatus=已完成` 的占比
- 上传恢复成功率 >= 99%
  - 口径：`completed / (completed + failed)`，统计幂等上传状态
- 移动端 API 性能（P95）< 500ms（不含大文件上传）
- 权限安全：移动端越权事件 = 0

## 运行步骤
1. 安卓端使用 `X-Client-Type=android` 和 JWT 登录。
2. 执行抽检上传（强制传 `Idempotency-Key`）。
3. 进入复核任务列表，完成确认/驳回。
4. 每日查看 `/v1/mobile/pilot/metrics` 与日志汇总。

## 风险与应对
- 弱网/断网：客户端重试同一 `Idempotency-Key`，服务端按幂等去重。
- 权限漂移：接口级授权和端能力限制双重校验（403）。
- 现场并发上传：通过上传状态查询接口避免重复提交。
