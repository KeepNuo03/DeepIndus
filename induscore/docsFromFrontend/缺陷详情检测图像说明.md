# 缺陷详情 - 检测图像展示说明

## 后端已实现

1. **详情接口统一返回图片地址**  
   `GET /v1/defect/{id}` 的响应 `data.imageUrl` 固定为：**`/v1/defect/{id}/image`**（相对路径）。  
   前端用 **API 的 baseURL + imageUrl** 即可得到完整图片地址，例如：`http://localhost:8000/v1/defect/123/image`。

2. **图片接口（免鉴权）**  
   - **GET /v1/defect/{id}/image**：按记录主键返回检测图像（JPEG），无图时返回 **404**。  
   - `{id}` 支持数字主键或检测编号，与详情接口一致。  
   - 该接口已加入免鉴权白名单，`<img src="...">` 不会因无 Token 被 401。

3. **上传时落盘**  
   - 离线检测 / 实时一帧上传时，后端会**优先用上传原图**写入 `exports/defects/{记录id}.jpg`。  
   - 新上传的记录在详情页通过上述图片接口即可看到图；老记录无文件则接口 404，前端可显示占位。

## 前端使用方式

在缺陷详情页的「检测图像」区域：

- 图片地址 = **API baseURL + detail.imageUrl**。  
  例如：`const imgSrc = axios.defaults.baseURL + detail.imageUrl` 或  
  `imgSrc = import.meta.env.VITE_API_BASE + detail.imageUrl`。
- 示例：`<img :src="apiBase + detail.imageUrl" alt="检测图像" @error="showPlaceholder" />`。  
- 当图片接口返回 404 时（老数据无图），在 `@error` 中切换为占位图或文案即可。
