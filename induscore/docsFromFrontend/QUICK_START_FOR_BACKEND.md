## 🎯 核心业务理解

### 系统业务流程

```
【生产前准备】
1. 管理员创建产品型号 → 配置质量标准 → 设置检测参数
2. 配置生产线 → 绑定摄像头 → 部署 AI 模型

【生产检测】
3. 开启实时检测 → AI 分析视频流 → 自动识别缺陷
4. 发现缺陷 → 自动拍照 → 生成检测记录 → 触发报警

【质量管理】
5. 质检员查询记录 → 查看缺陷详情 → 人工复核
6. 确认缺陷 → 记录处理流程 → 生成报告

【数据分析】
7. 查看数据大屏 → 分析趋势 → 优化生产
8. 对比模型性能 → 优化 AI 模型 → 提升准确率
```

## 💡 关键技术点

### 1. JWT 认证机制

**Token 包含信息：**
```json
{
  "userId": 1,
  "username": "admin",
  "roles": ["admin"],
  "exp": 1738579200
}
```

**前端存储位置：** `localStorage.getItem('token')`

**前端使用方式：** 每次请求 Header 中携带
```
Authorization: Bearer eyJhbGci...
```

---

### 2. WebSocket 实时通信

**连接建立：**
```
ws://localhost:8000/ws?token=xxx
```

**消息格式：**
```json
{
  "type": "detection",    // 消息类型
  "data": { ... }         // 业务数据
}
```

**前端监听：**
```javascript
wsClient.on('detection', (data) => {
  // 处理检测结果
});
```

---

### 3. 文件上传

**前端发送：**
```javascript
const formData = new FormData();
formData.append('file', file);
formData.append('name', 'model_name');

uploadModel(formData);
```

**后端接收：**
- 使用 multipart/form-data
- 保存文件到指定目录
- 返回文件 URL

---

### 4. 图表数据格式

**ECharts 需要的格式：**
```json
{
  "timeLabels": ["06:00", "08:00", "10:00"],
  "values": [12, 18, 45]
}
```

前端会将数据转换为 ECharts 配置。
