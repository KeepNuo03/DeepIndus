# PC+安卓双端功能边界与首期范围

## 产品定位
- PC 端：生产线全量检测与管理中台（全功能）。
- 安卓端：现场巡检、抽检、复核和异常协同（轻量作业端）。

## 安卓端首期范围（P0）
- 登录与工作台（待办、告警、上传状态）。
- 巡检/复核任务列表（仅轻量字段）。
- 抽检拍照上传（单图，弱网可重试）。
- 缺陷复核（确认/驳回 + 备注）。
- 消息通知（严重缺陷、待复核提醒）。

## 安卓端明确不做
- 模型管理（模型/版本 CRUD、部署、切换）。
- 用户/角色/部门管理。
- 生产线高级配置与复杂管理。
- 记录全量复杂检索与批量删除/导出。
- 大屏与经营分析配置。

## 移动端接口分层原则
- 安卓端只走 `/v1/mobile/**`。
- PC 管理接口保留原路径，不直接暴露给安卓。
- 认证统一 JWT，授权按“端类型 + 角色/权限”双重校验。

## P0 页面与接口上限建议
- 页面：不超过 6 个（登录、工作台、任务列表、抽检上传、复核详情、通知）。
- 接口：不超过 10 个（避免首期范围失控）。

## 首期接口建议（10个）
1. `POST /v1/auth/login`
2. `GET /v1/mobile/workbench`
3. `GET /v1/mobile/tasks/review`
4. `POST /v1/mobile/tasks/{id}/review`
5. `POST /v1/mobile/uploads/sampling`
6. `GET /v1/mobile/uploads/{idempotencyKey}`
7. `GET /v1/mobile/notifications`
8. `GET /v1/mobile/tasks/review/{id}`
9. `GET /v1/mobile/profile`
10. `GET /v1/mobile/pilot/metrics`

## 验收口径（P0）
- 巡检/抽检任务闭环率 >= 95%。
- 弱网重试后上传恢复成功率 >= 99%。
- 移动端 API P95 < 500ms（上传类接口除外）。
- 移动端无越权访问（权限审计通过）。
