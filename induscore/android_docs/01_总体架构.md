# 总体架构

## 目标
明确双端系统的职责边界与数据流，避免“PC 功能全部照搬到安卓”。

## 架构说明
- `PC Web (Vue3)` 通过 `HTTP/REST` 调用 `Spring Boot`。
- `Android (Kotlin + Compose)` 通过 `HTTP/REST` 调用同一套 `Spring Boot`。
- `Spring Boot` 连接 `MySQL`（主数据）与外部 `YOLO` 服务（服务端推理）。
- `Android` 本地使用 `Room(SQLite)`，仅用于离线缓存与上传队列，不作为主数据源。

## 职责边界
- PC 端：
  - 全量检测、模型管理、权限管理、产线/产品管理、记录管理。
- 安卓端：
  - 现场抽检上传、复核任务处理、通知查看、弱网重试。
  - 登录后进入系统主页，通过模块按钮进入各功能页。

## 与 Spring Boot 的关系
- Spring Boot 不负责安卓页面开发。
- Spring Boot 负责安卓端所需业务接口、权限控制、统一数据口径。
- 安卓端只是客户端，通过 API 消费后端能力。
