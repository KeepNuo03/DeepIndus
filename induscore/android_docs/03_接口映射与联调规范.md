# 接口映射与联调规范

## 目标
确保安卓页面与后端接口一一对应，减少联调歧义。

## 全局请求规范
- Header:
  - `Authorization: Bearer <token>`
  - `X-Client-Type: android`
- 上传接口额外 Header:
  - `Idempotency-Key: <UUID>`

## 页面与接口映射
1. 登录页  
   - `POST /v1/auth/login`

2. 系统主页（模块入口）  
   - 本地导航页，不直接调用后端接口

3. 工作台页  
   - `GET /v1/mobile/workbench`

4. 复核任务列表页  
   - `GET /v1/mobile/tasks/review?page=1&pageSize=20&status=all`

5. 复核任务详情页  
   - `GET /v1/mobile/tasks/review/{id}`

6. 复核提交  
   - `POST /v1/mobile/tasks/{id}/review`

7. 抽检上传页  
   - `POST /v1/mobile/uploads/sampling`

8. 上传状态页  
   - `GET /v1/mobile/uploads/{idempotencyKey}`

9. 通知页  
   - `GET /v1/mobile/notifications?limit=10`

10. 试点指标页  
   - `GET /v1/mobile/pilot/metrics`

11. 个人信息页  
   - `GET /v1/mobile/profile`

## 错误码处理规范
- `401`：未登录/Token 过期，跳转登录。
- `403`：无权限或端类型不允许，提示后停留当前页。
- `404`：目标任务或上传状态不存在，提示刷新。
- `500`：服务异常，写入失败队列并触发重试。

## 安卓代码对接位置
- API 定义：`android-app/app/src/main/java/com/induscore/mobile/data/remote/MobileApiService.kt`
- 登录仓储：`android-app/app/src/main/java/com/induscore/mobile/domain/AuthRepository.kt`
- 业务仓储：`android-app/app/src/main/java/com/induscore/mobile/domain/MobileRepository.kt`
- 导航入口：`android-app/app/src/main/java/com/induscore/mobile/ui/InduscoreMobileApp.kt`

## 风险
- 接口字段演进可能导致客户端解析失败，建议后端新增字段保持向后兼容。
