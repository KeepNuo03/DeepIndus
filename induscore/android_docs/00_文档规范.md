# 文档规范

## 1. 目标
保证安卓相关文档结构统一、内容可执行、更新可追踪。

## 2. 统一规则
- 全部使用中文。
- 每个技术文档至少包含：`目标`、`实现`、`风险`、`下一步`四部分。
- 涉及代码时必须标注项目路径（如 `android-app/app/src/...`）。
- 涉及接口时必须写清：请求方法、路径、关键参数、返回核心字段、错误码处理。

## 3. 变更维护
- 后端接口变动：同步更新 `03_接口映射与联调规范.md`。
- Room 表结构变动：同步更新 `04_Room数据库设计.md`。
- 上传重试策略变动：同步更新 `05_离线上传与重试机制.md`。
- YOLO 推理方案变动：同步更新 `06_YOLO安卓部署方案.md`。

## 4. 权威性约定
- `android_docs/` 为安卓侧规范文档主目录。
- 与其他目录文档冲突时，以 `android_docs/` 为准。
