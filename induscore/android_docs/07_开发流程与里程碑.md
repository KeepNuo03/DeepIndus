# 开发流程与里程碑

## 目标
将安卓端从脚手架推进到可试点上线版本。

## 阶段划分

### 阶段A：脚手架与基础联通（已完成）
- 建立 `android-app` 工程
- 打通登录、工作台、任务列表基础页面
- 接入 Room 与 WorkManager 基础结构

### 阶段B：核心业务闭环（进行中）
- 复核任务详情页
- 复核提交
- 抽检上传（拍照/选图）
- 上传状态查询页

### 阶段C：弱网与稳定性（待开始）
- 完整失败重试与重试上限策略
- 队列清理策略
- 错误分类与可观测日志

### 阶段D：试点与验收（待开始）
- A-01 线体联调试点
- 指标达标后准备扩大范围

## 建议工作流
- 分支建议：`feature/android-*`
- 每个功能单独 PR，必须包含联调记录
- 每日同步接口变更到 `android_docs/03_*`

## 风险
- 全栈单人开发容易在安卓细节上耗时，应优先保障主链路闭环。

## 下一步
- 优先完成阶段B，形成可演示版本。
