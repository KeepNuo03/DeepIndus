# 测试与验收标准

## 目标
建立安卓端可执行测试集与上线准入标准。

## 核心测试场景

### 1) 登录与鉴权
- 正常登录成功并跳转工作台
- token 失效后自动回登录
- 未带 `X-Client-Type` 时移动接口正确报错

### 2) 任务流
- 列表可加载、可分页
- 详情可打开
- 复核提交后状态更新正确

### 3) 上传流
- 正常上传成功
- 同 `Idempotency-Key` 重试不重复入库
- 失败后自动重试，重试次数递增
- 上传状态接口返回正确

### 4) 弱网场景
- 断网时入队成功
- 恢复网络后自动补传
- 本地文件缺失时给出明确错误

### 5) 权限与安全
- 移动端无法访问 PC 管理接口
- 403/401 处理符合预期

## 验收指标（首期）
- 任务闭环率 >= 95%
- 上传恢复成功率 >= 99%
- 关键接口 P95 < 500ms（上传除外）
- 越权事件 = 0

## 上线门槛
- 关键路径无阻断 bug
- 弱网重试通过完整回归
- 试点线体连续 3 天稳定

## 下一步
- 增加自动化回归（最少覆盖登录、任务列表、上传流程）。
