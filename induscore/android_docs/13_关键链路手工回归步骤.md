# 关键链路手工回归步骤

## 前置条件
- Spring Boot 服务启动，端口 `8000`
- Android 模拟器启动
- `android-app` 已安装运行
- 登录账号可用（例如 `admin/123456`）

## 回归路径 A：登录与主页
1. 打开 App，输入账号密码登录。
2. 验证登录后进入“系统主页”。
3. 验证模块按钮可点击进入对应页面。

## 回归路径 B：任务与复核
1. 系统主页 -> 复核任务。
2. 点击“查看详情”进入详情页。
3. 选择“通过”或“驳回”并提交。
4. 返回列表，确认状态更新或提示正确。

## 回归路径 C：上传与状态
1. 系统主页 -> 抽检上传。
2. 相册选择或拍照，点击“加入上传队列”。
3. 系统主页 -> 上传状态。
4. 验证队列中出现任务，状态从 `pending/uploading` 变化。

## 回归路径 D：弱网恢复
1. 断网后执行上传入队，确认可入队。
2. 恢复网络后点击“立即同步队列”。
3. 对 `failed/dead` 任务点击“手动重试该任务”。
4. 点击“仅重试超重试任务（dead）”，验证只处理 `dead` 任务。
5. 点击“清理终态记录（dead+completed）”，验证历史终态记录可按策略清理。
6. 验证“最近操作记录”卡片新增对应日志（动作、条数、成功/失败、提示信息）。
7. 验证失败任务可恢复，或按上限提示人工处理。

## 回归路径 E：通知 / 个人 / 指标
1. 系统主页 -> 通知中心，验证列表加载。
2. 系统主页 -> 个人信息，验证字段加载。
3. 管理员账号可见“试点指标”并验证字段与格式；非管理员账号不可见该入口。

## 回归路径 F：真实产线试点压测（弱网+蜂窝切换）
1. 按 `14_真实产线试点压测方案.md` 准备现场网络与测试数据集。
2. 先执行“稳定 Wi-Fi 基线”并记录闭环率。
3. 执行“弱网抖动（Wi-Fi）”并记录恢复成功率。
4. 执行“Wi-Fi 断开 -> 蜂窝切换”，验证阈值告警、取消与继续行为。
5. 执行“蜂窝阈值边界”（3/4 条任务、19/21MB）并记录结果。
6. 将结果回填到 `15_真实产线试点压测记录模板.md`，输出达标结论。

## 错误码专项检查
- 401：Token 失效后，页面提示“登录已过期”
- 403：无权限访问时提示权限错误
- 404：查询不存在资源时提示刷新
- 500：服务异常时给出兜底提示
