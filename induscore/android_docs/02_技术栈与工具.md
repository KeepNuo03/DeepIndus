# 技术栈与工具

## 目标
确定“最小可落地”的安卓技术栈，避免过度设计。

## 开发语言与IDE
- 语言：`Kotlin`
- IDE：`Android Studio`

## 安卓最小技术栈
- UI：`Jetpack Compose`
- 网络：`Retrofit + OkHttp`
- 本地数据库：`Room`
- 后台任务：`WorkManager`
- 并发：`Kotlin Coroutines`

## 选型理由
- Kotlin + Compose 是安卓官方主线，长期维护成本更低。
- Retrofit 适合快速对接现有 REST 接口。
- Room 适合离线缓存与上传队列场景。
- WorkManager 对弱网重试、后台恢复最稳定。

## 当前项目已搭建脚手架
- 安卓工程目录：`android-app/`
- 入口文件：`android-app/app/src/main/java/com/induscore/mobile/MainActivity.kt`
- 依赖配置：`android-app/app/build.gradle.kts`
- 默认后端地址：`android-app/app/src/main/java/com/induscore/mobile/config/AppConfig.kt`

## 风险
- 真机调试时 `BASE_URL` 需改为局域网 IP，不能继续使用 `10.0.2.2`。
